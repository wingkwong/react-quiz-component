## How it works

Shuffling happens when a session is created. Changing the React `key` remounts the component and clears the previous answers. A new shuffle may produce the same order. Prepared answer indexes and callback payloads follow the shuffled choices.

## Implementation

Install `react-quiz-component`, then copy this component and the `quiz.ts` data file into the same directory. `Quiz` loads its own stylesheet automatically. The preview mounts in the browser; Next.js applications should use a client boundary.
