## Implementation

`useQuiz` provides quiz state and actions without rendering or styling an interface. This example builds a custom UI. For a complete styled quiz with no custom CSS, use the [default `Quiz` component](./default.mdx).

Install `react-quiz-component`, then copy this component and the `quiz.ts` data file into the same directory. The preview mounts in the browser; Next.js applications should use a client boundary.

<ExampleSource name="hook" />

## Custom styles

Save this stylesheet as `examples.css` alongside the component. The implementation imports it to style the layout, answer buttons, selected answers, and keyboard focus. The CSS uses the documentation theme colors when available, with fallback colors for your own application.
