## Try the quiz

Start the quiz to begin the 60-second countdown. Pause, resume, then answer the questions or let the timer expire.

<ExamplePreview name="quiz-timer" />

## How it works

The timer starts when the quiz starts. Pausing excludes paused time from the budget. Expiry completes the quiz with the answers collected so far; untouched questions remain unanswered.

## Implementation

Install `react-quiz-component`, then copy this component and the `quiz.ts` data file into the same directory. `Quiz` loads its own stylesheet automatically. The preview mounts in the browser; Next.js applications should use a client boundary.
