## How it works

`continueTillCorrect` applies to immediate single-answer questions. Retrying does not recover points lost on the first attempt. Multiple-answer questions are evaluated once the required number of choices is selected.

## Implementation

Install `react-quiz-component`, then copy this component and the `quiz.ts` data file into the same directory. `Quiz` loads its own stylesheet automatically. The preview mounts in the browser; Next.js applications should use a client boundary.
