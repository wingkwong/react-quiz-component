## Implementation

`Quiz` includes its own styled interface and loads its CSS automatically. No stylesheet import or custom CSS is required.

Install `react-quiz-component`, then copy this component and the `quiz.ts` data file into the same directory. The preview mounts in the browser; Next.js applications should use a client boundary.
