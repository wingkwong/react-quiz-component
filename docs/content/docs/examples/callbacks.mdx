## How it works

`onQuestionSubmit` runs when an immediate attempt is evaluated; `onComplete` runs once per completed session. This example uses `showDefaultResult={false}` without a custom renderer, so the completion UI belongs to the surrounding application. The payloads shown here remain local to this demo. See [Callbacks and results](../callbacks.mdx) for deferred-mode delivery and payload details.

## Implementation

Install `react-quiz-component`, then copy this component and the `quiz.ts` data file into the same directory. `Quiz` loads its own stylesheet automatically. The preview mounts in the browser; Next.js applications should use a client boundary.
