## Try the quiz

Start the quiz and watch the 15-second question countdown. Pause and resume, or let a question expire to advance automatically. The final question expiry completes the quiz.

<ExamplePreview name="question-timer" />

## How it works

Each question receives its own budget. Expiry locks the question; untouched questions remain unanswered and partial multiple-answer selections count as incorrect. You can also combine `questionTimer` with an overall `timer`.

## Implementation

Install `react-quiz-component`, then copy this component and the `quiz.ts` data file into the same directory. `Quiz` loads its own stylesheet automatically. The preview mounts in the browser; Next.js applications should use a client boundary.
