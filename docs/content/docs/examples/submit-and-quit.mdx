## Try the quiz

Start, answer the first question, and pause the timer. Choose Submit and quit, cancel once to keep the session, then confirm to finish with partial results.

## How it works

`allowQuit` offers a confirmed exit after the quiz starts, including while paused. Cancelling preserves the session; confirming stops the timer and shows results. Untouched questions remain unanswered and partial multiple-answer selections count as incorrect.

## Implementation

Install `react-quiz-component`, then copy this component and the `quiz.ts` data file into the same directory. `Quiz` loads its own stylesheet automatically. The preview mounts in the browser; Next.js applications should use a client boundary.
