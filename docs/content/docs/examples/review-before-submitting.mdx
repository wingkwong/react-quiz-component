## How it works

`revealAnswerOnSubmit` keeps correctness hidden until completion and lets you edit selections. It takes precedence over immediate feedback and correct-answer highlighting. `allowNavigation` permits skipping and revisiting questions, but submission requires complete answers. An incomplete submission shows an alert; a complete submission asks for confirmation.

## Implementation

Install `react-quiz-component`, then copy this component and the `quiz.ts` data file into the same directory. `Quiz` loads its own stylesheet automatically. The preview mounts in the browser; Next.js applications should use a client boundary.
