## Dependency Upgrades

This maintenance release updates the project's build tools, test tooling, and documentation dependencies. The versions below show the changes since 2.1.0.

### Build and development tooling

| Package | Previous version | Updated version |
| --- | --- | --- |
| `@babel/core` | 8.0.9 | 8.1.0 |
| `rollup` | 4.65.0 | 4.67.5 |
| `tslib` | 2.8.1 | 2.9.1 |
| `@types/node` | 26.6.5 | 26.6.6 |
| `pnpm` | 12.15.0 | 12.18.0 |

### Testing and linting

- Updated `vitest` from 5.0.5 to 5.1.0.
- Updated `oxlint` from 1.89.0 to 1.91.0.

The workspace lockfile and dependency release-age exceptions have been updated alongside these upgrades.

## Upgrading from 2.1.0

Update `react-quiz-component` to 2.1.1 using your package manager:

```sh
npm install react-quiz-component@2.1.1
```

No application code migration is required. This release introduces no changes to quiz APIs, props, or quiz data formats. React 18 and React 19 remain supported, and the library's direct runtime dependencies (`nanoid`, `sanitize-html`, and `snarkdown`) retain their existing versions.
